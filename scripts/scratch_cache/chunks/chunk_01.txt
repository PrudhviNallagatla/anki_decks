SQL Tuning
Lab Exercise 1
1. You are working as a DBA. Users are complaining about long running queries
and high execution times. Configure your database instance to log slow queries.
Any query taking more than 5 seconds must be logged.
2. After logging slow queries you found following query taking longer than
expected time
SELECT * FROM customers JOIN orders USING(customerid);
3. View the explain plan of the above query.
4. View the execution time for the above query in terminal.
edb-psql
Answer Lab Exercise – 1
1. Open a Terminal and login as enterprisedb. Type
su – enterprisedb
2. Edit the postgresql.conf file to log slow running queries. Type
vi /var/lib/edb/as17/data/postgresql.conf
3. Change the parameter to
log_min_duration_statement 5000
4. Save and close the file Type
<ESC>:wq <Enter>
5. Reload the server. Type
pg_ctl -D /var/lib/edb/as17/data reload
6. Go to the database as the edbuser Type
edbstore
and enter the edbuser password
psql edbstore edbuser
7. View the explain plan. Type
EXPLAIN SELECT * FROM customers JOIN orders
USING(customerid);
8. View the execution time of the above query. Type
EXPLAIN ANALYZE SELECT * FROM customers JOIN orders
USING(customerid);

Extensions
Lab Exercise – 1
In this lab, you will be working with a Postgres extension to enhance the functionality of your
database.
1. Install and configure extension named hstore in edbstore database
2. Perform a basic test or use case that demonstrates the functionality provided by the
extension
Answer Lab Exercise - 1
1. Go to the edbstore database as postgres. Type
psql edbstore enterprisedb
2. Install the extension hstore. Type
CREATE EXTENSION IF NOT EXISTS hstore;
3. Here is a sample use case for hstore extension.
--Create a table with hstore column:
CREATE TABLE messages (
message_id SERIAL PRIMARY KEY,
sender_id INT,
receiver_id INT,
message_text TEXT,
metadata HSTORE
);
--Multirow Insert statement to add six rows:
INSERT INTO messages (sender_id, receiver_id, message_text,
metadata)
VALUES
(1, 2, 'Hello, how are you?', 'sent_at => "2023-01-07
12:30:00", priority => "low"'),
(2, 1, 'All is well. How about you?', 'sent_at => "2023-
01-07 12:31:00", priority => "low"'),
(1, 2, 'Fine Thank You. What is the release data for
PostgreSQL 16', 'sent_at => "2023-01-07 12:32:00", priority =>
"high"'),
(2, 1, 'Its planned for Oct 2023', 'sent_at => "2023-01-07
12:35:00", priority => "high"'),
(1, 3, 'Oct 2023', 'sent_at => "2023-01-07 12:37:00",
priority => "high", type => "Marketing"'),
(1, 4, 'Oct 2023', 'sent_at => "2023-01-07 12:38:00",
priority => "high", type => "Sales"');
--List high priority messages:
SELECT message_id, sender_id, receiver_id, message_text FROM messages
where metadata -> 'priority' = 'high';
